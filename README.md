# Grundwissen Physik

Die Seite, auf der Schülerinnen und Schüler ihr Grundwissen Physik üben –
Gymnasium in Bayern, LehrplanPLUS (G9).

**→ https://pru19.github.io/GrundwissenPhysik/**

Die Karten kommen aus dem Grundwissensregister des Unterrichtsarbeitsbereichs
und sind dieselben, die auf den ausgeteilten Grundwissensblättern stehen. Der
QR-Code auf einem Blatt führt unmittelbar auf sein Kapitel.

## Datenschutz

Keine Anmeldung, keine Auswertung, keine Übertragung. Der Lernstand liegt
ausschließlich im Browser des jeweiligen Geräts (`localStorage`) und verlässt es
nicht. Es gibt weder Konten noch Tracking noch Nachladen von fremden Servern –
die Seite ist eine einzige Datei und läuft auch offline.

## Erzeugt, nicht geschrieben

`index.html` wird von `_Skripte/baue_uebung.py` aus dem Register erzeugt und
hierher kopiert. Änderungen gehören ins Register, nicht in diese Datei – sie
würden beim nächsten Lauf überschrieben.
